# Privacy Policy

**YouTube Auto Translate** does not collect, sell, share or transmit personal data.

## Data stored

The extension stores one value locally in your browser profile:

- `enabled` — whether automatic translation is turned on.

This value is stored with `chrome.storage.sync`, so Chrome/Edge may sync it between devices signed in to the same browser account. It contains no personal information.

## Comment content

The extension does not read, copy, store or transmit comment text. It only locates YouTube's native translate button inside the page and clicks it. The translation request is sent by YouTube itself, under YouTube's own privacy policy.

## Network requests

The extension makes no network requests to any server owned by this project. It has no analytics, telemetry, advertising or remote configuration.

## Permissions

- `storage` — save the on/off setting.
- Host access to `youtube.com` — required to find comment elements and click YouTube's native translate button.

## Third parties

No third-party services, SDKs or trackers are used.
